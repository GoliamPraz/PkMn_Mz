📖 How to Build from Source

Linux / macOS

git clone https://github.com/GoliamPraz/PkMn_Mz.git
cd PkMn_Mz
g++ main.cpp -lraylib -lGL -lm -lpthread -ldl -lrt -lX11 -o game
./game

Windows

git clone https://github.com/GoliamPraz/PkMn_Mz.git
cd PkMn_Mz
g++ main.cpp -lraylib -o game.exe
game.exe

🎮 Game Features
  • 🕹️ Navigate a procedural maze
  • 🎯 Collect green power-ups for 5 second boosts
  • 👾 Avoid black enemies (they chase you)
  • 🏃 Blue enemies flee from you during power-ups
  • ❤️ Health system (1.00 - 10.00)
  • 📊 Score tracking and high scores
  • ⌨️ Keyboard controls: Arrow Keys or WASD
