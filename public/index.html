WebAssembly версията е в разработка. За сега, използвай десктоп версията:

🐧 Linux / macOS

Изтегли и изпълни локално:

git clone https://github.com/GoliamPraz/PkMn_Mz.git
cd PkMn_Mz
g++ main.cpp -lraylib -lGL -lm -lpthread -ldl -lrt -lX11 -o game
./game
🪟 Windows

Изтегли репозиторито и компилирай с:

g++ main.cpp -lraylib -o game.exe
game.exe
ℹ️ За разработване на render.com

WebAssembly компилирането е сложно за сървъри. Препоръка: инсталирай локално и се забавлявай!
